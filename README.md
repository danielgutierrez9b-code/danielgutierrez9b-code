## 👨‍⚕️ Médico | 📊 Data Analyst

Profesional del sector salud con formación en **Análisis de Datos**, orientado a convertir datos complejos en **insights accionables y soluciones basadas en evidencia**.

### 🛠️ Technical Skills

* **Python:** análisis y manipulación de datos, automatización y exploración de datasets.
* **SQL:** consultas, transformación y análisis de bases de datos.
* **Data Visualization:** desarrollo de visualizaciones para comunicar hallazgos y tendencias.
* **Machine Learning:** aplicación de modelos y técnicas de aprendizaje automático a problemas de análisis de datos.
* **Data Analysis:** limpieza, exploración, análisis estadístico, identificación de patrones y generación de insights.

### 🏥 Healthcare + Data

Mi experiencia clínica me proporciona una perspectiva especializada para analizar problemas del sector salud desde una visión **data-driven**. Combino conocimiento del ámbito sanitario con herramientas de análisis para transformar datos en información útil para la toma de decisiones.

### 🎯 Focus

* 📈 Optimización y análisis de procesos.
* 🔎 Identificación de patrones y tendencias.
* 💡 Generación de insights accionables.
* 🏥 Analítica aplicada al sector salud.
* 🤖 Automatización y soluciones basadas en datos.
* 🚀 Innovación y transformación digital.

Este repositorio reúne proyectos y ejercicios desarrollados durante mi formación en **Data Analysis**, demostrando la aplicación práctica de **Python, SQL, visualización de datos y machine learning** a problemas de análisis reales.
